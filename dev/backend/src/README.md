# 🚚 Cargonaut – Backend  
**NestJS • PostgreSQL • Prisma • Docker • WSL2 • GraphQL**

Dieses Repository enthält das Backend des Cargonaut-Projekts – einer Mitfahr- und Mittransport-Lösung, die Fahrer und Mitfahrer effizient miteinander verbindet.

**Aktueller Stand:**  
Das Grundgerüst des Backends ist vollständig eingerichtet:

- NestJS Projektstruktur  
- PostgreSQL Datenbank via Docker  
- Prisma ORM konfiguriert (Migration erfolgreich angewendet)  
- User-Modul (Model, Controller, Service) implementiert  
- Registrierung (inkl. Passwort-Hashing) vorbereitet  
- WSL2 + Docker + ARM64 Umgebung vollständig kompatibel  
- Backend startet fehlerfrei
